# Kavira-Inventory-and-Supply-Analysis-(Ongoing)

## 1. Introduction

This project explores inventory data from an African supermarket to understand which of the business' products are taking longer to sell out as well as identifying possible factors contributing to the decline in sell-out performance.

The goal is to use data to identify slow or unsold products, uncover possible factors behind their performance, and support better-informed inventory and restocking decisions.
